# Vesper Standard Time

What if time worked with us? Vesper Standard Time (VST) is a concept clock that nudges the hours and minutes to match how your body actually experiences a day — not the rigid 60-second tick of a standard clock.

**Live:** [vesperstandardtime.com](https://vesperstandardtime.com/)

> "Your body loves routine. VST finally gives it one."

## How it works

The interface shows time in three modes side by side:

- **VST** — the adjusted Vesper time
- **Standard** — regular clock time for reference
- **Split** — the drift between the two, in seconds

## Built with

HTML, CSS, and JavaScript — deployed via Netlify. Originally prototyped in Google AI Studio.
